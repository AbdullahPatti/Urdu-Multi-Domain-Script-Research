HOW TO READ THIS FILE
--------------------------------------------------------------------------------
Each step = one experiment run.
TRAIN FILE  = load this file, fine-tune the model on it
TEST FILE   = after training, evaluate the model on this file
TYPE        = IN-DOMAIN (source==target) or CROSS-DOMAIN (source!=target)
RESULT FILE = save macro-F1 + accuracy + classification report here

Complete ALL runs for one model before starting the next model.
Within a model, complete ALL runs for one task before the next task.

HYPERPARAMETERS (same for every run):
  Model checkpoint:  see MODEL ID column per section
  Max epochs:        5
  Early stopping:    patience=3 on validation loss (10% of train set)
  Learning rate:     2e-5
  Batch size:        16 (reduce to 8 if GPU OOM)
  Max seq length:    128
  Optimizer:         AdamW with linear warmup
  Metric:            macro-F1 (primary), accuracy (secondary)
